# inventory_planning

Goal - Create Reusable Planning Dashboard to Upload ALL Order Data - where we can parse MINI, Kit and Tallboy Data to define how many MInis we need. 

Expectations - Data is somehow stored and referenced. Data Can be updated / adjusted based on current Data. 

What we Need to make this Work 

Kit part Data - What 3 mini tubes are included in a Kit - Is there a Rimmer (3 cube tubes - 18 Cubes / 2 mini tubes - 12 cubes )
Mini Data - 6 cubes total - What Flavor Label is needed (Cafe, Mimosa, Bellini, Craftt Beverage etc. LM005-PB = Strawberry Premium Bellini Mixer in a Cube)

Tallboy - ~30 cubes 
1/2 pound Bulk Bag - ~50 cubes
